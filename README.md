# Republic Bricks — Telegram web version

Compiled Unity web build updated on 2026-11-01.

Monetag main zone 12166349 replaces AdsGram. Only voluntary Rewarded Interstitial ads are requested, after an information/choice dialog inside Telegram. The SDK uses the official tag supplied by the publisher dashboard: https://libtl.com/sdk.js.

Only a valued confirmation with the matching zone and request ID refills lives, up to five. Early close without a valued confirmation, errors or missing results do not grant an advertising reward. No automatic interstitials or rewarded popups are enabled by the game.

Publisher payouts, including PayPal settings and eligibility, are managed in the publisher's private Monetag account. No payment data or Telegram bot token is included in this game build.
